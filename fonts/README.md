# Self-hosted fonts

These font files ship with World Static so the glasses app never requests a
CDN. Each family is licensed under the SIL Open Font License 1.1. The license
text is in the family folder.

- **Rajdhani** (default HUD) — Indian Type Foundry, OFL 1.1, `fonts/rajdhani/OFL.txt`
- **Inter** — The Inter Project Authors, OFL 1.1, `fonts/inter/LICENSE.txt`
- **JetBrains Mono** — The JetBrains Mono Project Authors, OFL 1.1, `fonts/jetbrains-mono/OFL.txt`

Only the Latin woff2 cuts used by the app are included.
